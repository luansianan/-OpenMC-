# 建模细节与几何反解依据

## 1. 几何参数的反解

文献表 2 只给出：

```
Fuel rod inner/outer diameter   1.651 / 2.210 mm
Helium gap thickness            0.254 mm
Shell thickness                 0.316 mm
Lattice diameter ratio          1.7144
Component box thickness         1.016 mm
Component box side length       56.134 mm
```

存在两个歧义：**(1)** “Fuel rod inner/outer diameter” 是环形芯块的内/外径，还是芯块外径/包壳外径？**(2)** “Component box side length” 是六角盒的**对边**还是**边长**？

用 `scripts/measure_fig1.py` 对论文图 1(a) 做连通域统计，得到：

| 观测量 | 测量值 | 推论 |
|---|---|---|
| 燃料棒圆斑数 | **91**（5 环六角栅格 1+3·5·6） | 组件共 91 根燃料棒 |
| 栅距/圆斑直径 | **1.77** | 与表中 “Lattice diameter ratio = 1.7144” 一致 → 该值就是 P/D |
| 棒束填充盒内宽的比例 | **0.93**（x、y 两方向一致） | 棒束几乎充满组件盒 |
| 盒的 高/宽 | **0.867** | 六角形（√3/2），宽度方向是**对角**尺寸 |

把「91 棒 + P/D = 1.7144 + 盒对边 56.134 mm」联立：

```
棒束对边跨度 = 10·P·cos30° + D = 8.660·(1.7144·D) + D = 15.85·D
要求 ≈ 0.93 × (56.134 − 2×1.016) = 50.3 mm
⇒ D ≈ 3.17 mm，P ≈ 5.44 mm
```

而按「芯块 2.210 + 2×(气隙 0.254 + 包壳 0.316) = 3.350 mm、P = 1.7144×3.350 = 5.743 mm」则得到棒束跨度 53.1 mm（填充率 98 %）。两者都在测量误差内，因此 **表 2 的 “Fuel rod inner/outer diameter” 应读作环形芯块的内/外径**（这也与“fuel rod 有 inner diameter”的字面含义一致）。

由于该参数仍存在残余歧义，`model.py` 提供 `--pellet solid|annular` 两种解读，工作结果同时给出（见 README 第 3.2 节）。

## 2. 材料定义

| 材料 | 组成（原子分数） | 密度 | 说明 |
|---|---|---|---|
| UO₂ | ²³⁵U 5 % / ²³⁸U 28.3 % / O 66.7 % | 10.94 g/cm³ | O/U = 2 恰好化学计量 ⇒ 这些百分比是**原子**百分比；富集度 = 5/33.3 = **15.02 %**，对应文献表 3 的 14.83 %（质量富集度）行 |
| HT-9 | Fe 70 % / Cr 11.5 % / Mo 1 % | 7.8 g/cm³ | 文献只给这三种元素，按天然同位素丰度展开（Fe 4 种、Cr 4 种、Mo 7 种） |
| Pb-Bi | Pb 44.3 % / Bi 55.7 % | 10.29 g/cm³ | 共晶 LBE；Pb 按天然同位素展开（204/206/207/208） |
| He | ⁴He 100 % | 1.78×10⁻⁴ g/cm³ | 芯块中心孔与气隙，约 1 atm |

**体积极限的推论**：芯块 Ø2.210 / 棒 Ø3.350 的棒在三角栅格中的燃料体积份额为

```
f_fuel = (π/4 · d_pellet²) / (√3/2 · P²) = (π/4) / (√3/2 · (P/D_rod)²) · (d_pellet/D_rod)²
```

取 P/D = 1.7144 得 **13.8 %**（实心芯块）；即使把栅距压到棒贴棒（P/D = 1）也只有 **39.5 %**。这正是“密排极限”算例 `scripts/bound_pincell.py` 的物理基础，也是判断文献 k_eff 与其参数不自洽的关键依据。

## 3. 边界条件与统计

- 组件盒外表面 **全反射**：等价于无限阵列中的单个组件，即 k_∞。这与文献“2-D 组件模型”的定位一致，也是该棒型能达到的**最大** k（任何轴向泄漏只会更低）。
- `Leakage Fraction = 0.00000 ± 0.00000` 在输出中证实了反射边界生效。
- 该模型燃料体积份额低（6–14 %）、几乎不吸收，中子随机游走步数极多：实测吞吐约 **900 粒子/秒**（12 线程），即文献的 500 批 × 20 000 粒子需要约 3 小时。由于单批方差小，**σ(k_eff) < 0.001 只需约 10 个活性批**；因此生产算例取 45 / 30 批 × 20 000 粒子（σ ≈ 8×10⁻⁴），兼顾精度与耗时。

## 4. 工具链验证

`scripts/validate_godiva.py` 用同一套 ENDF/B-VIII.0 + NJOY 加工的库计算裸高浓铀球：

```
GODIVA: k_eff = 1.00071 ± 0.00073   (实验值 1.0000，偏差 +71 pcm)
```

这排除了核数据加工（NJOY 重建容差 2 % 等）与输运计算引入系统偏差的可能。
